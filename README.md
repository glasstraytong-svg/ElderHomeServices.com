# Elder Home Services
Website for our family's in-home senior care business.

**Live site (once GitHub Pages is enabled):** https://glasstraytong-svg.github.io/ElderHomeServices.com/

## To publish via GitHub Pages
1. Go to the repository **Settings → Pages**.
2. Under "Build and deployment", set **Source** to `Deploy from a branch`.
3. Choose the `main` branch and `/ (root)`, then Save.

## Before going live
Replace the placeholder contact details in `index.html`:
- Email: hello@elderhomeservices.com
- Service area and hours
- The contact form currently only shows a confirmation; hook it up to a form service (e.g. [Formspree](https://formspree.io)) to receive messages.
